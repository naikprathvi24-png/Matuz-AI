# Matuz AI

## Matuz AI – Intelligent Study Assistant

Matuz AI is an AI-powered study assistant built with Python, Streamlit, and Groq API.

It helps students:

- Summarize study notes
- Extract important points
- Generate questions and answers
- Analyze PDF, DOCX and TXT files
- Analyze study images
- Interact using voice
- Maintain user accounts
- Save previous conversations

## Features

- Notes Summarization
- Important Points Extraction
- Question Generation

## Technologies

- Python
- Streamlit
- Gemini API

## Run Project

```bash
streamlit run app.py
```
